PRE-ICFES - EJECUCION NORMAL CON PYTHON
======================================

Abre la carpeta del proyecto en VS Code (la que contiene manage.py).
Necesitas Python 3.12 o 3.13.

PRIMERA VEZ
1. Abre una terminal en VS Code.
2. Crea el entorno virtual (recomendado):
   python -m venv .venv
3. Activalo:
   - CMD: .venv\Scripts\activate.bat
   - PowerShell: .\.venv\Scripts\Activate.ps1
   Si PowerShell bloquea la activacion, usa CMD.
4. Ejecuta estos comandos:
   python -m pip install -r requirements.txt
   python manage.py migrate
   python manage.py crear_usuarios_prueba
   python manage.py runserver

CADA VEZ QUE QUIERAS INICIARLO DESPUES
1. Activa el entorno virtual en la terminal de VS Code.
2. Ejecuta solo:
   python manage.py runserver

No necesitas archivos .bat ni .ps1 para iniciar Django.
Los scripts originales se conservan como opcion alternativa.
No vuelvas a crear la base ni los usuarios cada vez que inicies.

Abre el sitio: http://127.0.0.1:8000/
